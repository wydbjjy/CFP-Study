## 工作原理

本仓库使用 Claude Code 作为交互式 CFP 考试导师，它能够：
- 使用苏格拉底式教学法（先询问你了解什么）
- 提供简洁的解释（约 200 词）
- 通过后续问题验证你的理解
- 根据你的回答调整教学风格
- **追踪每次学习课时，为你个性化定制学习体验**

## 使用方法

### 每日学习

1. 在本仓库中打开 Claude Code
2. 自然地提问数一高数相关主题——像与数学导师对话一样
3. 回答 Claude 提出的理解检查问题
4. 每次课时后，Claude 会自动记录：
   - 你学到了什么
   - 你在哪些方面感到困难
   - 你掌握了什么
   - 下一步需要复习什么

### 复习

当你想复习时，直接告诉 Claude：
- "我们来复习一下我之前感到困难的主题"
- "今天我应该重点关注什么？"
- "出几道题考考我薄弱的地方"
- "展示我的学习进度"

Claude 会读取你的课时历史，根据你过去的表现创建个性化的复习方案。

### 追踪你的进度

查看 `/progress/cfp-study-tracker.md` 中的综合学习追踪器：
- 全部 84 个数一高数主题的进度
- 已掌握主题与信心水平
- 知识缺口及其严重程度
- 参考书籍及使用建议（含教材、辅导书、习题集、真题、模拟卷共 17 本）

## 学习理念

**引导式学习方法：**
- 对话式、无评判压力
- 在你已有知识的基础上构建
- 前进前检查理解程度
- 适应你的学习风格
- 注重深度理解，而非死记硬背
