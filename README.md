## 数一考试概况

数学一是考研数学中内容最广、要求最高的类别，涵盖高等数学（约 56%）、线性代数（约 22%）、概率论与数理统计（约 22%）。本仓库当前专注于**高等数学部分**（约 84 分），覆盖全部 84 个知识点（A-H 共 8 大领域）。

## 工作原理

本仓库使用 Claude Code 作为交互式考研数学一导师，它能够：
- 使用苏格拉底式教学法（先询问你了解什么）
- 提供简洁的概念解释（约 200 词）
- 用数一真题风格的例题检查你的理解
- 根据你的回答调整教学方式
- **追踪每次学习课时，为你个性化定制学习体验**

## 使用方法

### 每日学习

1. 在本仓库中打开 Claude Code
2. 自然地提问数一高数相关主题——像与数学导师对话一样
3. 回答 Claude 提出的理解检查问题
4. 每次课时后，Claude 会自动记录：
   - 你学到了什么
   - 你在哪些方面感到困难
   - 你掌握了什么
   - 下一步需要复习什么

### 复习

当你想复习时，直接告诉 Claude：
- "我们来复习一下我之前感到困难的主题"
- "今天我应该重点关注什么？"
- "出几道数一真题考考我薄弱的地方"
- "展示我的学习进度"

Claude 会读取你的课时历史，根据你过去的表现创建个性化的复习方案。

### 追踪进度

查看 `/progress/cfp-study-tracker.md` 中的综合学习追踪器：
- 全部 84 个数一高数主题的进度
- 已掌握主题与信心水平
- 知识缺口及其严重程度
- 参考书籍及使用建议（含教材、辅导书、习题集、真题、模拟卷共 17 本）

## 学习理念

**引导式学习方法：**
- 对话式、无评判压力
- 在你已有知识的基础上构建
- 前进前检查理解程度
- 适应你的学习风格
- 强调几何直观和物理意义
- 注重深度理解，而非死记硬背

## 参考书籍

本仓库配套推荐 **17 本参考书**，按四个阶段使用：

| 阶段 | 用书类型 | 推荐书目 |
|------|---------|---------|
| 基础夯实 | 教材 + 基础习题 | 同济《高等数学》第七版 + 660 题 |
| 深化拓展 | 辅导书 + 强化习题 | 张宇 18 讲 / 1000 题 等 |
| 综合提升 | 辅导书 + 专题训练 | 复习全书 + 880 题 |
| 真题冲刺 | 真题 + 模拟卷 | 历年真题 + 预测卷 |

完整书单见 `cfp-study-tracker.md`。

## 核心特点

**个性化学习**：
- 苏格拉底式教学法（在你已有知识基础上构建）
- 根据你的回答自适应解释
- 针对薄弱环节定制练习题
- 重视数一高频考点和常见陷阱

**全面追踪**：
- 每次课时自动记录
- 识别并追踪知识缺口
- 已掌握主题附信心水平
- 根据数一分值权重衡量进度

**严谨验证**：
- 每道题亲自完整计算再给出答案
- 积分结果通过求导验证
- 绝不凭记忆给结论
- 写出完整推导过程
